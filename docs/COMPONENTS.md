# 構成要素の診断と流れ表示

## 同じモデルの検査ビュー

全体、減速機、圧縮機、燃焼器、タービンを切り替えます。
圧縮機は x = 0.84–2.04 m、燃焼器は 2.03–2.44 m、タービンは 2.43–3.26 m の観察窓です。
軸方向に切り出すだけで、翼、ディスク、支持部、軸の親子関係や回転を組み替えません。
見えない範囲の描画を省き、窓の境界には描画のクリッピングを適用します。

ケースは初期状態で透過します。部品ごとに材質を分け、ケースの透過が軸受支持部などへ伝播しないことを検査します。
1/4・1/2カットと透過は独立した操作です。

## 17段の設計入力

Fan 1、LPC 3、HPC 8、HPT 2、LPT 3 の各動翼列を選択し、対応する3D形状を強調します。
速度三角形は、固定70%設計点の平均半径について C = U + W を描きます。
局所の翼進行方向を +θ、エンジン軸方向を +x とし、入口と出口の図は同じ速度縮尺です。

Euler 仕事は Δh = U (Cθ₂ − Cθ₁)。圧縮機は正、タービンは負で表示します。
3つの半径でベクトル和と段仕事を検査し、全段の仕事をサイクルの要求仕事・ガス側仕事と照合します。
タービンのガス側仕事と機械効率適用後の軸出力は区別します。

この三角形は翼の取付角を定める設計入力です。翼間流れの解、翼面の入射・偏差角や損失の予測ではありません。
翼形状と設計三角形は固定で、オフデザインのサイクルは説明用の合成特性によります。

## 運転中のエネルギー収支

現在の `EngineState.cycle` の境界温度・圧力・質量流量から、エンタルピー変化を別途再計算し、
サイクルが返す構成要素の出力と照合します。表示する残差はこの独立した再計算との差です。

| 対象     | 確認する関係                                                                        |
| -------- | ----------------------------------------------------------------------------------- |
| 圧縮機   | Fan + LPC + HPC の軸仕事 = 空気のエンタルピー増加。ファンはバイパス空気の仕事も含む |
| 燃焼器   | ṁg h₄ − ṁa h₃ = ηb ṁf LHV、ṁg = ṁa + ṁf。説明用の燃焼効率 ηb = 0.99                 |
| タービン | ガスのエンタルピー低下 × 機械効率 0.98 = HPT + LPT の軸出力                         |
| 2軸      | タービン出力 − 圧縮機・ファン負荷 − 損失 = I ω dω/dt。LP と HP を別々に積分         |

燃焼器の噴射器、ドーム、内外ライナは静止した部品として選択できます。
燃焼反応、保炎、冷却孔や希釈空気の個別流れはモデル化していません。

## 流れの読み方

断面平均の一次元圧縮性流れから、コアとバイパスの経路、移動矢印、軸方向グラフを生成します。
3D、凡例、グラフは同じ状態と表示量を参照します。

| 表示量   | 固定スケール |
| -------- | ------------ |
| 全温 Tt  | 250–1,800 K  |
| 全圧 Pt  | 0.08–2.2 MPa |
| 軸流速度 | 0–650 m/s    |

色の範囲は運転点によらず固定で、色の自動再正規化はしません。3Dの色には照明やトーンマッピングを適用しません。
経路は流路の内外壁の間に置き、矢印は同じ計算時刻で局所平均速度を積分して移動します。
見やすさのため経路を前面に重ねています。矢印はコアとバイパスに同数を置き、本数や線幅で質量流量比は表しません。
グラフではコアを実線、バイパスを破線に分け、現在の検査範囲を帯で示します。

TIME の 1/1200〜実時間、一時停止、微小ステップは、歯車、全ロータ、流れに共通です。
矢印の移動は計算時刻を使い、アニメーション専用の別時計では進めません。
これは平均流れの可視化で、CFD の翼後流・剥離・旋回流線・乱流場を表すものではありません。

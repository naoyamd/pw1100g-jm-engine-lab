# ベンチマークの実施記録

実施日：**2026-09-05（日本時間）**。
GPT-6 Astra が調査方針、統合、描画・UI、検証、公開を担当し、
GPT-5.6 Luna のサブエージェントが根拠調査、減速機、翼・軸形状、サイクル、流れ表示、構成要素の診断を分担しました。
単一モデル・単発プロンプトのスコアではなく、ユーザーの追加指示を含む反復開発の記録です。

数値の正本と集計時点は [`data/benchmark.json`](../data/benchmark.json) に保存しています。
サイト下部の実施記録を開くと、総数、入力、キャッシュ入力、出力、モデル別の内訳を確認できます。

## トークンの数え方

- 対象はこのタスクと、その配下の調査・実装サブエージェント。今日の他タスクからの推計は使っていません。
- ローカルの `token_usage_record` にある、応答 ID ごとの `usage` を一意に合算しました。
- 各タスクの合計は、記録の `thread_token_usage` と一致することを確認しています。途中でリセットされる表示用カウンターの最終値は使いません。
- 総量は入力＋出力です。キャッシュ入力は入力の内数、推論出力は出力の内数で、二重に加算しません。
- 同じ文脈を繰り返し入力するキャッシュの読込も含みます。生成した文章の文字数、最終コンテキスト長、課金額とは異なる量です。
- Codex の承認自動レビュー、記録されなかった使用量、集計時点より後の公開確認・報告は含めません。

これは取得できた利用記録のスナップショットです。アカウント全体の請求・使用率との一致は主張しません。
公開したのは集計値と方法のみで、会話、応答 ID、端末上のパスなどの生ログは含めていません。

入力・出力・内訳の一般的な定義は [OpenAI Responses API の usage](https://developers.openai.com/api/reference/typescript/resources/beta/subresources/responses/methods/create) も参照してください。

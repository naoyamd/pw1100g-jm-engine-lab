# 検証記録

PW1100G-JM Engineering Lab は公開情報に基づく機構・サイクルの再構成です。
実機の製造形状、性能マップ、強度、耐久性を同定したモデルではありません。
検証対象を「公開資料に合う構成」「構築したメッシュ」「計算状態」「ブラウザ表示」に分けています。

## 再現するコマンド

Node.js 24、クリーンな依存インストールから実行します。

```sh
npm ci
npm run check
GITHUB_PAGES=true npm run build
npm run prepare-pages
```

Windows PowerShell では環境変数を `$env:GITHUB_PAGES='true'` と設定してからビルドします。
型検査は Node.js から TypeScript を実行します。JavaScript ファイルを関連付けソフトで開く操作は不要です。
GitHub Actions も同じ型検査・lint・テスト・静的ビルドを公開前に実行します。

Windows / Node.js 24.19.0 では静的 HTML の生成完了後に、ビルドプロセスが
`UV_HANDLE_CLOSING` の assertion で終了コード1を返す事象を断続的に確認しています。
原因は未特定です。成功扱いにする回避処理は入れず、公開成果物は Linux の GitHub Actions で生成します。
ローカル開発サーバーと上記の型・数値・形状検査は正常に動作しています。

流路の検査は4つの定常指令だけでなく、10%→100%と100%→10%の各20秒過渡でも行います。
実機の翼間流れを再現する CFD ではなく、断面平均の連続式を満たす一次元の可視化です。
翼の仕事とねじれは公称のモデル運転点に対応し、オフデザイン特性は合成マップによります。
コアの流路内壁には翼の軸方向の広がりを考慮した、説明用の10 mmすきまと12 mm壁厚を設けています。
これらは実機の翼端すきまではなく、サイクルの面積は断面平均流れに対応する有効面積です。

歯車は61のLP位相、5スター、左右のヘリックス、各軸方向断面で、
同じ作用線上の接触点が両方の実メッシュから20 µm以内にあることを検査します。
既定の6分割ヘリックスを使った独立レビューでは、位相を0.37サンプルずらし、
両端面の2,440か所を再検査して最大距離2.192 µm、未成立0件でした。
この距離は歯面のポリゴン近似誤差で、製造精度や弾性変形の予測ではありません。

## 物理ソルバー

定常解は LP / HP の軸出力を同時に釣り合わせます。ファンとスターの反映慣性を含め、
過渡状態は中点法でトルクを積分します。歯車効率とタービンの機械効率を別に扱い、
タービンの速度三角形は機械効率適用前のガス側エンタルピー差から作ります。

20秒応答を 0.02 / 0.01 / 0.005 s の刻みで照合した検査では、
運動エネルギーと中点軸仕事の相対差は 0.02 s で最大 6.21e−4、0.005 s で最大 3.80e−5。
刻み幅を小さくすると誤差が減り、粗い刻みと細かい刻みの最終回転数差は相対 1e−7 未満でした。
数式、計算範囲、合成値は [PHYSICS.md](PHYSICS.md) を参照してください。

## 表示

背景、操作パネル、計器、グラフをライト配色で統一しています。
3D は Three.js の金属・粗さモデル、環境反射、照明、影によるリアルタイム描画です。
画像や動画への置き換えではなく、カット面も動くメッシュから毎フレーム生成します。
画面寸法に合わせたカメラ調整で、全体・減速機・圧縮機・燃焼器・タービンの検査範囲を収めます。
ケース透過と流れ表示を初期状態で有効にし、時間倍率は観察用の1/600としています。
繰り返す同形の翼は同じロータ・ステータの中で一括描画します。
変換前後の全インスタンスについて形状の同一性と世界座標行列の差 ≤ 1e−6 を検査し、
最適化によって翼の形状、位置、回転系が変わらないことを確認します。

ローカルブラウザでは、10%と100%の定常到達、途中の軸出力差、停止中の時刻保持、
微小ステップ後の Sun 約0.01309 rad / Fan 約−0.00436 rad を確認しました。
1440×1000と390×844の表示を検査し、横はみ出しとモバイルのカメラ操作領域を確認しています。
一括描画後の通常パネル幅で、全体カット表示は約40〜50 FPS、減速機は約60 FPSでした。
これはこのローカルPC・ブラウザでの観測値で、端末や画面寸法によって変わります。

切断面の検証で、端面と側面の向きが不一致になる不具合を検出しました。
体積の符号と辺の本数だけでは検出できないため、共有辺の向きの検査を追加しています。

追加の表示検査では、全温・全圧・軸流速度の切り替え、5つの検査ビュー、動翼列の選択、
速度三角形の正負（HPCは正、タービンは負）、停止中の時刻保持、1/1200への切替を確認しました。
停止中の微小送りでは Sun の差 +0.0131 rad / Fan の差 −0.0044 rad、描画角度残差0でした。
実施日とトークン内訳は画面下部に折り畳んで記録します。方法は [BENCHMARK.md](BENCHMARK.md) を参照してください。

## 確認範囲の限界

整数歯数からの速度比、剛体拘束、平均流れの保存則が成立することを確認します。
歯面の弾性接触・潤滑膜・熱膨張・クリープ・振動・軸受寿命・支持部の応力は対象外です。
ゼロバックラッシは拘束運動を検証する理想化で、製造公差の指定ではありません。
実機の全運転域、実測推力、騒音、燃費を予測する用途には使えません。
